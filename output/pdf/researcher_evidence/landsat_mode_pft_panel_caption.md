# Figure 4 caption

Plant functional types across three Landsat-mode products. **A**, Lines show category medians and shaded ribbons show the interquartile range (25th–75th percentiles) of footprint-level normalized spectra. Every spectrum, including SWIR bands when available, is divided by its own B1–B5 sum before calculating medians and quartiles. Ribbons describe variability among sampled footprints, not uncertainty in the median. Counts follow legend order: HLS cells, NEON polygons and drone polygons. **All real-Landsat curves, ribbons, counts and HLS pairwise-gap strips now use the same expanded 496-cell, 24-patch Landsat HLS L30 NBAR (v2) reference cohort as B**: deciduous 77, evergreen 110, herbaceous 99, shrub 165 and non-vegetated/dead 45. The previously plotted Collection 2 Niwot spectra are retained only as historical evidence and do not enter this figure. HLS values are BRDF-normalized B1–B7 reflectance from the selected 2023/2024 regional observations; provisional photo/structural reference limitations apply to A as well as B. NEON repeat years are averaged within polygon before normalization; drone pixels are summarized by polygon medians. NEON spectra retain the synthetic OLI products. Drone spectra use native MicaSense B1–B5 proxies and have no B6/B7 observations. The three strips show absolute differences between category medians multiplied by 100 for each sensor pair and band; black cells have no shared band. These are descriptive differences across distinct sensor samples, dates, regions and footprint sizes, not matched-sensor bias estimates.

**B**, The Separability columns summarize pairwise evidence; Identifiability columns summarize held-out recall. NEON Separability values report supported contrasts against four other categories across four site-years, using Holm-adjusted p ≤ 0.05. NEON Identifiability values report mean class recall on unseen polygons / held-out sites. These tests use all seven synthetic OLI bands. Landsat entries (†) use BRDF-normalized Landsat HLS L30 NBAR (v2) from the expanded 95% nominal-footprint reference cohort: **496 cells in 24 spatial patch groups** (deciduous 77 cells/five patches, evergreen 110/three, herbaceous 99/five, woody shrub 165/seven, non-vegetated/dead 45/four). Four new shrub patches and one exposed-rock patch were interpreted using public aerial imagery before their HLS spectra were retrieved. Pale soil, deep darkness, boundary belts and unreviewed areas remain excluded/unknown under the same photo-cover rules as the existing references. Patch grouping prevents adjacent cells from becoming independent training/test replicates. Panels A and B use the same HLS reference cells. A summarizes normalized individual-cell spectra; B tests direct-reflectance patch medians, so the summary unit and normalization differ explicitly. Panel B uses direct B1–B7 NBAR reflectance patch medians without plot normalization.

Landsat Separability reports supported/testable exact whole-patch NPC contrasts against four other categories, with synchronized max/integrated statistics, equal band weights and Holm correction across all ten planned pairs. All ten pairs are testable; three pooled contrasts meet adjusted p≤0.05. The class rows share those contrasts and are not independent test families. Pooled patch exchangeability across regions/seasons is a strong assumption; insufficient evidence for a pair does not establish equivalence. Within-region tests and their support limitations are archived separately. Reference collection and analysis have been exploratory across multiple stages; the current ten-pair adjustment does not constitute preregistered confirmation or control across all earlier analytical looks.

Landsat Identifiability is held-out **patch-median class recall**, with correct/total counts. A fixed StandardScaler + balanced logistic regression (C=1) is fitted only to equally weighted training patch medians for every whole-patch holdout. Overall 21/24 patch medians are correct (87.5%): deciduous 4/5 (80%), evergreen 3/3 (100%), herbaceous 5/5 (100%), shrub 6/7 (86%) and non-vegetated/dead 3/4 (75%). Every target class is present in training for this evaluation. Predictions for each patch, secondary pixel predictions and held-region training-class support are retained; new-region performance is not established.

The original 95% cover definition applies to the nominal 30 m HLS footprint. The additional 120×120 m, 4×4-source-pixel cover requirement is now treated as a conservative sensitivity, rather than a standard HLS purity requirement. Its expanded subset contains 161 cells in 13 patches and yields no supported pooled contrasts; non-vegetated/dead still has only one patch, preventing five-class held-class evaluation. This unweighted source-area diagnostic is not signed cubic interpolation weights or a confidence bound. Sample selection materially affects the evidence and both complete cohorts are archived. As an additional explicitly predictive diagnostic, pairwise held-patch balanced accuracy averages 97.6% across the ten binary tasks (50% chance); it is an estimate of discrimination, not another significance test and does not replace the NPC entries. No model/feature tuning was performed to select a favorable score.

All HLS labels remain provisional and independently unvalidated. Non-evergreen references use dated photo interpretation; evergreen uses older (2016/2018) lidar first-return structure >5 m and provisional 2023 evergreen identities, not measured current PFT cover. HLS Fmask/scaling and footprint geometry were rebuilt for this source. BRDF normalization does not imply identical geometry/model or topographic correction to AOP. Sensors' reference units, cohorts and evaluation protocols differ, so table rates are not controlled sensor-comparison estimates.

Drone entries (‡) are newly calculated exploratory evidence from 243 distinct verified physical-reflectance polygons at Ruby and Goldhill (5 deciduous, 159 evergreen, 31 herbaceous, 32 woody shrub, 16 non-vegetated). Tests use the five native band proxies, unnormalized polygon medians, 9,999 synchronized whole-polygon label permutations within sites containing both compared classes, the package max/integrated NPC statistic, equal discrete band weights, and Holm correction across the ten prespecified category pairs (unavailable tests contribute p=1 for correction). Nine pairs are testable; deciduous and non-vegetated have no common site. Six pairs meet adjusted p ≤ 0.05. Drone Separability reports supported/testable pair counts, so denominators vary from three to four and are distinct from the NEON pair/cohort denominator. Identifiability uses a fixed StandardScaler + balanced logistic regression (C=1), with all preprocessing fit on training polygons: five stratified polygon folds and two leave-one-site-out folds. Each polygon contributes exactly once per evaluation scheme. Recall is pooled across held-out polygons within class. The archived NEON identifiability protocol differs; these rates are not controlled model comparisons. Deciduous and non-vegetated each occur at only one calibration site; their held-site class recall is NA because their class is absent from training. Predictions and training-class support flags are preserved. These are calibration-library evaluations without independent external-site validation.

OLI/OLI-2-like labels describe analogous band families. The supplied AOP table retains the legacy `olioli_undarkened` seven-band representation with centers [443, 482, 561, 655, 865, 1609, 2201] nm; its metadata does not establish OLI-2-specific response convolution. Package metadata distinguishes Landsat 8 OLI from Landsat 9 OLI-2. Drone curves and tests use native MicaSense [444, 475, 560, 668, 842] nm proxies, not newly convolved or empirically translated OLI-2 reflectance. Label edits do not change response functions or data.
