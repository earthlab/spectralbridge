# Google Docs editing copies

`SpectralBridge-main.docx` and `SpectralBridge-SI.docx` are editable import copies
of the current manuscript and SI. Upload them to Google Drive and open them with
Google Docs. Save as native Google Docs if you want Google-format documents.

The copies include readable citations and references, embedded figures, author
metadata, and editable equations. All 23 SI tables are editable Word tables,
reconstructed from the source PDF's column positions. Wrapped source lines remain
individual table rows where the PDF does not encode semantic row boundaries;
review row grouping during substantive table edits.

The author-input notes in the main manuscript are retained for completion by the
team. These collaboration copies do not replace `../paper.md`, `../paper.bib`,
`../supplement.md`, or `../supplement.bib` as the JOSS sources. Return edited Docs
exports for reconciliation with those sources before rebuilding the JOSS preview.

No documents have been imported into Google Drive or shared. The Google Drive
plugin was not installed when these copies were prepared. Native import can proceed
after it is installed and connected; import mode must be `native_google_docs`.
