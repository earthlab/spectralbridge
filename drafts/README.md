# Publication sources moved

Canonical manuscript and SI sources now live in [paper/](../paper/README.md).
Original PDFs/extractions are under `paper/archive/`; renders, check records and
Google Docs editing exports are under `paper/generated/`. There is one editable
source for each manuscript; the old `drafts/joss/` directory is not a second source.

Old `drafts/joss/` file paths are compatibility symlinks so previously shared
editing-file links continue to resolve. They point to the same canonical or
generated files, not independently editable copies. Builds use `paper/` directly.
