# Archived Generated Docs Reports

Created: 2026-06-02

The files in `docs/_build/` are generated by the documentation drift tools, not
hand-authored documentation. They were moved here during publication cleanup so
the active docs tree contains source pages only.

Regenerate current reports with:

```bash
python tools/doc_drift_audit.py
python tools/apply_doc_fixes.py
```

The tools will recreate `docs/_build/` when needed.
