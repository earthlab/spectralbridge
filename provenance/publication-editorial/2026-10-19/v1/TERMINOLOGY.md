# Active-site terminology dictionary

| Term | Meaning / editorial rule |
| --- | --- |
| SpectralBridge | Scientific/software name; not the import or distribution name |
| earthlab-spectralbridge | Distribution metadata name; no PyPI project exposed at the audit date |
| spectralbridge | Python import namespace |
| cross-sensor-cal / cross_sensor_cal | Historical project or intentional compatibility aliases; not current distribution instructions |
| NEON | Observed airborne hyperspectral source; full support means the validated retained grid, not every raw union-schema column |
| synthetic OLI | Same-source derived sensor representation; never independent Landsat validation |
| actual Landsat | Independently acquired satellite observations with their own spatial/temporal/QA support |
| researcher categories / cover_category | Five recorded categories; primary grouping, not historical species-derived PFTs or certified pure materials |
| separability | Distribution differences under the stated sampling/exchangeability design |
| identifiability (recognition) | Held-out category recognition in empirical learning pages; distinguish from mathematical inverse uniqueness |
| inverse identifiability | Whether distinct admitted compositions can map to the same observation |
| abundance / synthetic fractions | Recovery of known algebraic mixture weights in the described benchmark |
| field abundance | Independently measured biological fractional cover; not established |
| MESMA | Candidate endmember mixture search within explicit finite-library/component constraints |
| FCLS | Nonnegative sum-one constrained spectral fit; ideal-real theorem differs from tolerance-limited numerical implementation |
| ridge | Conditional supervised fraction predictor; unique fitted coefficients do not establish unique physical inversion or intrinsic superiority |
| endmember / reference library | Retained candidate spectra and provenance; labels do not establish material purity |
| candidate ambiguity | Alternatives among the evaluated retained solutions at a stated tolerance; not exhaustive physical uncertainty |
| exhaustive search | Every declared finite candidate at stated numerical rules; not all possible physical mixtures |

Current synthesis retains difference → identity → quantity → uniqueness → field
validation. Reference-library quality and information loss supply supporting
questions, not replacement evidence levels. Historical snippets are explicitly
labelled superseded; no historical record is rewritten to enforce this dictionary.
