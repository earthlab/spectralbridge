SpectralBridge

SpectralBridge is scientific Python software for preparing and comparing reflectance across airborne, drone and satellite sensor representations. It serves remote-sensing researchers who need traceable intermediate products, restart-safe processing and explicit quality checks.

Three separate workflows process NEON flightlines, supported local drone imagery, and collections of completed products. Spectral libraries and numerical analysis methods support downstream research. Configured sensor-like bands do not establish agreement with independent sensor observations or field fractional cover.

Install and verify

The distribution is earthlab-spectralbridge; the Python import is spectralbridge. Python 3.10–3.12 is the tested release range.

At the 19 October 2026 audit, PyPI did not expose this distribution name. Use the source installation below. Repository HEAD identifies 2.3.0rc1, which is a candidate identity rather than a published release. Create a virtual environment, then run:

git clone https://github.com/earthlab/spectralbridge.git
cd spectralbridge
python -m pip install -e .
python examples/first_example.py

The tiny example inspects an invented spectral table without downloads or credentials. It verifies software use, not scientific accuracy. Continue the beginner path.
