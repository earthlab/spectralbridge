# Whole-spectrum methods review

Reviewed 2026-10-14, before implementing the comparison. This review separates published procedures from the explicit blocked adaptations proposed here. No method below automatically supplies valid exchangeability blocks, independent taxa or a sampling design.

## Comparison of inferential targets and design handling

In the table, **R/B/S** means repeated plant / flight-site blocking / species nesting. “Via design” requires aggregation, restricted exchangeability or a correctly specified model; it is not an intrinsic feature of an ordinary two-sample implementation. All mean claims below require appropriate error/covariance assumptions if the null is weaker than equality of distributions.

| Method | Null / covariance and sample-size assumptions | R/B/S handling | Global / local inference and permitted claim |
| --- | --- | --- | --- |
| A. Current scaled maximum | Exchangeable whole curves within blocks; sensitive to localized mean contrast. Joint resampling preserves covariance without inverting it. Unequal n valid under exchangeability, unequal covariance not a mean-only guarantee | All via design; S is unaddressed by plant permutation | Global max probability; simultaneous max-band evidence possible; H1/H2 |
| B. Permutation functional ANOVA / integrated norm | Equality of mean functions under the FANOVA model, or strong exchangeability for exact permutation. Integrated squared contrast accumulates broad differences; preserves covariance via resampling. Unequal n changes weighting; heteroscedastic mean-null needs a suitable calibration | All via design; multifactor adaptation is not ordinary one-way FANOVA | Global integrated/F probability; localization requires separate simultaneous procedure; H1/H2 |
| C. Global envelopes | Exchangeability of observed and simulated functional statistics. Unscaled, variance-scaled, rank/ERL orderings differ in power. Unequal n enters the generating contrast; envelope construction does not repair invalid resampling | All via generator; not automatic S adjustment | Global probability plus simultaneous graphical excursion; H1/H2 on the generating statistic |
| D. Functional linear response model | Selected coefficient function equals zero given identifiable covariates; residual dependence and nuisance handling must be valid. Full wavelength covariance can be modeled or respected in resampling | R via covariance/random effects, B fixed effects, S only if identifiable | Global tests and simultaneous coefficients possible; conditional coefficient association |
| E. Functional mixed effects | Fixed coefficient zero / variance component / predicted functions, depending on test; requires identified hierarchy, covariance model and enough independent clusters/taxa | Explicit nested/crossed R/B/S possible; not when effects are exactly aliased or one species represents a population | Model-dependent global/joint posterior inference; conditional H4 only under extra species-population assumptions |
| F. FPCA + multivariate model | Equality of projected score means, not all possible functional differences. Label-blind PCA preserves major covariance; truncated components may discard a low-variance PFT signal. Unequal n and covariance still matter | Same valid units and block model; species alias remains | Global projected test; score loading localization is descriptive without simultaneous reconstruction |
| G. PERMANOVA | No group/location effect in chosen distance geometry under a specified model/permutation scheme; heterogeneous dispersion and unbalanced n complicate centroid interpretation | Restricted permutations and multifactor models possible; ordinary label shuffle not multilevel adjustment | Global pseudo-F; no direct valid wavelength localization; not “all distributions identical” in general |
| H. Energy distance | Equality of distributions (not only means) in a specified metric; finite first distance moment. Detects spread/shape as well as location; unequal group sizes affect bias/power, not exact conditional permutation validity | Two-sample code needs design-aware adaptation; species replication not invented | Global distributional test; cannot identify a causal absorption band |
| I. MMD | Equality of distributions for a characteristic kernel and suitable moment/boundedness conditions; kernel/bandwidth affects power. Covariance differences are alternatives, not automatically false positives | Restricted permutation / clustered construction required; ordinary iid calibration insufficient | Global kernel test; witness functions are not automatically simultaneous wavelength evidence |
| J. Hotelling / high-dimensional mean tests | Equal mean vector; classical covariance inversion requires adequate rank and model assumptions. Chen–Qin avoids inversion but has high-dimensional covariance/moment conditions; many correlated bands plus tiny groups are not an automatic fit | Design/cluster extension needed; ordinary asymptotics do not adjust species | Global mean test; regularization or projections change target; local evidence separate |
| K. Functional MANOVA | Equal selected vector-valued functional effects in an identifiable design with covariance/model conditions | Potential factorial design, repeated effects require extensions | Global multigroup/functional test; using four deterministic products as independent outcomes adds no independent evidence |
| L. GAM/GAMM PFT×wavelength | Zero smooth interaction/function conditional on covariates and basis/penalty/random-effect model; smoothing uncertainty and residual wavelength dependence must be included | Can encode R/B/S with sufficient replication; many scalar wavelengths do not create many plants | Model-based global smooth test; simultaneous smooth intervals require more than pointwise SEs |
| M. Gaussian-process functional regression | Covariate/PFT mean function or posterior effect under a kernel/hierarchy; flexible within-/between-curve covariance, but priors/kernel and approximate inference matter | Can model R/B/S if identified; computationally heavier and not a repair for taxonomy aliasing | Posterior or calibrated predictive claims; credible bands are not design-based permutation envelopes |
| N. Spatial ecological functional response model | Reflectance explained jointly by environment, taxonomy and space–wavelength structure under its model; requires credible coordinates, environmental covariates and validation | Explicit spatial/dependence modeling; hierarchy tailored to available taxonomy | Environment/space-aware association and out-of-sample spectral prediction; no generic pure-PFT mechanism |

## Interpretability, feasibility and software maturity

| Method | Local interpretation / limitations | Cost and implementation maturity | Publication suitability for this dataset |
| --- | --- | --- | --- |
| A | Direct signed coefficient; maximum emphasizes one region | B×n×bands; existing tested NumPy implementation | Strong transparent baseline for narrow conditional claim |
| B | Integrated signal does not alone locate a region | Same resampling cost; R fda.usc, Python scikit-fda support one-way FDA; custom blocking must be validated | Strong sensitivity; good component of a predeclared omnibus |
| C | Simultaneous null envelope, not an effect CI | Retain B×bands curves; mature R GET; scaled-MAD construction simple enough to verify independently | Recommended visualization; do not call a Python adaptation “GET ERL” |
| D | Coefficient functions interpretable given nuisance design | Python array/linear algebra and R fda/refund; functional response differs from scalar-on-function regression | Reduced block fixed-effects model supportable; saturated species+PFT not |
| E | Separates random functional components under modeling assumptions | R refund/pffr and WFMM; implementation and diagnostics substantially greater than permutations | Future measured-design analysis; not primary for this species-limited question |
| F | Clear covariance modes; can miss small-effect directions | Label-blind SVD cheap here; scikit-fda/R fda mature | Useful FDA sensitivity with a fixed variance/cap rule, not label-selected PCs |
| G | Geometry and dispersion interpretation need care | Mature R vegan adonis2/betadisper; Python ecological tools vary; quadratic distances | Reasonable alternative, but redundant with norm/projection here and not a design fix |
| H | Distributional separation with no band attribution | Quadratic n distance storage, blockwise calculation manageable; mature R energy | Recommended distributional sensitivity with explicit blocked adaptation |
| I | Bandwidth and kernel choices less intuitive | Quadratic kernel or approximations; mature research implementations, dependency choice needed | Valid option; energy avoids another tunable bandwidth for this audit |
| J | Inverse covariance may amplify unstable components | Classical T² unsuitable when covariance singular; projection/regularization feasible | Use label-blind reduced-rank model; no unqualified full-band T² |
| K | Multigroup effect versus pairwise contrast must be specified | R FDA and multivariate frameworks; requires matched model/testing implementation | No advantage for these planned binary contrasts |
| L | Smooth terms may hide narrow features or bridge gaps | R mgcv/refund mature; Python generic GAM packages do not automatically supply functional mixed inference | Potential observation-level follow-up; separate bases for disconnected spectral regions |
| M | Kernel assumptions can dominate sparse taxonomy effects | GPFDA in R; dense covariance scaling may be prohibitive without structured approximations | Too much modeling before fixing identifiability; no current need |
| N | Directly relevant to plant reflectance/environment, not generic one-way ANOVA | Published spatial-functional models require a targeted implementation and covariates | Best longer-term direction when spatial/trait data are prepared; not an automatic replacement now |

The covariance/unequal-n qualifications above are our design-specific assessment, not claims that each cited software package implements every hierarchy.

## Global envelopes in depth

[Myllymäki et al. (2017)](https://doi.org/10.1111/rssb.12172) develop global rank and scaled maximum-deviation envelopes. A valid generator is essential. A fixed null-centered contrast d(lambda), scaled by a label-invariant null spread a(lambda), gives M=max |d/a|. An order statistic of the **permutation maxima** supplies a simultaneous critical multiplier c; ±c*a(lambda) is a global null envelope. Pointwise 2.5/97.5% permutation quantiles do not implement this. This envelope is especially natural here because it retains the existing maximum test.

A conventional unscaled maximum uses common raw units and favors high-variance wavelengths. The existing test uses a fixed, label-independent scale; it is a variance-scaled MAD test, not per-permutation Welch studentization. A true Welch/studentized procedure re-estimates a group-sensitive standard error in every permutation, with different weak-null robustness assumptions. A global envelope from the current scale has the current strong exchangeability target.

[GET (Myllymäki & Mrkvička, 2024)](https://doi.org/10.18637/jss.v111.i03) provides established rank, ERL, scaled and other envelopes. Extreme rank uses the most extreme pointwise rank; ties can create an interval of p-values. ERL refines tied minima through lexicographically ordered rank profiles, retaining more distributed extremeness information. These are not equivalent to ranking raw plant reflectances band by band. Their simultaneous interpretation concerns simulated functional statistics. The [authors' definitions/software](https://cran.r-project.org/web/packages/GET/GET.pdf) should be used for reference implementations; this audit will not invent ERL from an informal description.

The [functional ANOVA envelope extension (Mrkvička et al., 2020)](https://doi.org/10.14736/kyb-2020-3-0432) directly demonstrates the relevance to curves. For this data we adapt the simulation generator to matched plant histories; we do not claim their ordinary one-way procedure itself handles species nesting. A simultaneous **null** envelope is not a confidence band for the biological effect. An integrated/NPC rejection can occur without any maximum-envelope excursion; that is expected and must be labeled. Across-contrast control requires a further family adjustment. Holm p-values and fixed Bonferroni envelope crossings need not coincide.
