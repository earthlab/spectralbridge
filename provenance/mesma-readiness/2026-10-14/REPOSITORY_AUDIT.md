# Repository and evidence reuse audit

Reviewed README, pyproject, architecture/agent guidelines, current source/test module inventories, examples, vignettes and recent provenance. The source is an immutable 85,706-row merged polygon Parquet; it is not a complete image archive. P120's checksummed compact summaries cover 12,504 observations, 4,807 polygon-years, 3,639 identities, three sites/four site-years and three native grids. P118 includes 1,143 species-null identities through researcher labels. PFT crosswalks preserve unresolved taxa. P117/P120 significance cannot establish mixture identifiability.

Reuse plant_spectral_atlas.harmonize_spectrum, compact extraction, exact wavelength fields and existing masks; plant_spectral_years acquisition parsing; plant_spectral_pfts crosswalk; sensor_pft_transfer pairing/physical OLI gate; pft_method_audit supported-band logic; existing hash/atomic provenance and plotting conventions. Read nearby tests before extending. Compact checkpoints are consumed directly, not copied or re-extracted for convenience. Original pixel table is opened only for projected metadata and bounded QC reductions.

Existing legacy MESMA is under deprecated/code/unmixing, including duplicated MesmaCore implementations and old library_oli.npy/class_list_oli.npy. It uses unconstrained SVD then filters fractions/shade, threaded pools and combinatorial lookup arrays, is explicitly deprecated, has no validated independent holdout/source memberships and assumes scaled reflectance. It is not an active installed API. It cannot simply establish current-library readiness. Do not revive or copy that implementation. file_types.py only describes historic output types.

P121's real Landsat comparison reuses public STAC and actual-cell aggregation: n=1 R10C next-day flight, pooled RMSE 0.01477 SR and angle 2.089 degrees, mixed brightness effects, conditional timezone and no independent abundance reference. Do not re-label it as real abundance validation or apply its residual covariance universally to this different library.

New work is additive and experimental: a small tested convex-mixture/selection module plus readiness orchestration, not a new operational processing pipeline or top-level stable API. No correction, sensor responses, brightness gains or existing ecological outputs are changed. Future full-image spatial coverage for NIWO/WREF/YELL requires their real source rasters; sparse polygon locations cannot substitute for it.

Existing boosted quantile lines and group atlas envelopes describe variability; they are not new independent empirical endmembers or mixture validation observations. This audit uses empirical source summaries throughout. Original polygon geometries are a promising independent annotation source, but selected, potentially overlapping/incomplete polygons and coarse ecoregions are not complete per-pixel reference fractions.
